# FLIMKit

Fluorescence lifetime imaging analysis in Python: reading vendor file formats, reconvolution fitting, phasor analysis and tile stitching.

FLIMKit runs as a desktop application or from the command line. It reads PicoQuant, Becker & Hickl, ISS and Photonscore files, fits mono- and multi-exponential decays against a measured or machine IRF, and stitches tiled acquisitions into a single fitted mosaic.

- [FLIMKit](https://github.com/FLIMKit/FLIMKit) is the main repository.
- [Documentation](https://flimkit.github.io/) covers installation, the workflows and the module reference.
- [Issues](https://github.com/FLIMKit/FLIMKit/issues) is the place for bugs, questions and format requests.

Sample files are the most useful thing anyone can contribute. Several readers were written from vendor specifications and have never been run against a real acquisition, and the supported formats table in the documentation says which are which.
